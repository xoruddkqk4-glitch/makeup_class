# 🏫 보강 알리미 (온라인 교무실 보강 현황 웹 앱)

구글 사이트(Google Sites) 기반 온라인 교무실에 임베드하여 사용하는 **학교 보강 관리 및 현황 공유 웹 애플리케이션**입니다.  
구글 사이트 임베드 환경에 최적화하여 **상단 세로 공간 및 모달창 높이를 대폭 축소한 콤팩트 레이아웃**, **보강 교사 전달 확인 체크박스**, **0초 즉시 반응 낙관적 UI 성능 최적화**가 적용되어 있습니다.

---

## 📌 주요 기능 (Key Features)

- ✅ **보강 교사 전달 확인 체크박스 (전달 확인 기능)**:
  - **셀 내 체크박스 배치**: 보강 교사 셀 카드 내부에 **체크박스** 및 **`🔔 미확인` / `✅ 확인완료` 뱃지** 배치
  - **원클릭 확인 토글**: 보강 교사가 해당 명단을 확인하고 체크박스를 클릭하면 카드 전체가 에메랄드 톤(`✅ 확인완료`)으로 즉시 변경되어 전달 여부 직관적 파악 가능
  - **DB 상태 자동 저장**: 체크 여부가 구글 스프레드시트 9번째 열(`확인여부`)에 비동기로 자동 저장
- 📐 **테이블 툴바 날짜 표기 1줄 고정 최적화**:
  - 기간 선택 시 날짜 정보(`[ 2026-08-31(월) ~ 2026-09-06(일) ]`) 텍스트 크기 축소(`0.775rem`) 및 `white-space: nowrap` 고정
  - 줄바꿈 없이 **항상 깔끔하게 1줄로 고정 표시**
- ⚡ **데이터 등록/수정/삭제/체크 반응 속도 획기적 향상 (성능 최적화)**:
  - **낙관적 UI (Optimistic UI)** 적용: 사용자 버튼 클릭 및 체크박스 토글 즉시 0초 만에 화면 변경 ➔ 백그라운드 구글 스프레드시트 비동기 동기화
  - **단일 네트워크 일괄 업데이트 (Bulk Update)**: `Code.gs`에서 `setValues([[...]])` 1회 일괄 업데이트로 수정 속도 7배 향상
- 🚪 **'학급' ➔ '교실' 체계 전면 개편 (드롭다운 순서: 4층 ➔ 3층 ➔ 2층 ➔ 1층 ➔ 지하)**:
  - **드롭다운 순서**: `4층` ➔ `3층` ➔ `2층` ➔ `1층` ➔ `지하(B층)` 순서로 정렬
  - **DB 열 이름**: 기존 `학급` 열 이름 ➔ **`교실` 열 이름으로 자동 수정/생성**
  - **교실 범위**: `4층(401~416)`, `3층(301~316)`, `2층(201~216)`, `1층(101~115)`, `지하(B01~B14)`
  - **등록 모달**: 층 선택(`4층`, `3층`, `2층`, `1층`, `지하(B층)`) ➔ 해당 층의 교실 목록 자동 갱신선택
- ↔️ **구글 사이트 전용 2열 가로 확장 모달창 (태그 확장 대응 최적화)**:
  - 좌측 열: `1. 날짜` ➔ `2. 교시` ➔ `3. 교실` ➔ **`4. 보강 교사`**
  - 우측 열: `5. 보강 유발 사유(커스텀 태그)` ➔ `6. 결강 교사(원교사)`
- 📐 **구글 사이트 임베드 전용 초슬림 콤팩트 레이아웃**:
  - 부가 설명 텍스트 및 중복 마진 제거 ➔ **'보강 알리미' 메인 제목만 슬림하게 배치**
- 🔔 **보강 교사 열 특별 시각화 강조 (핵심 기능)**:
  - **헤더 강조**: 진한 에메랄드 딥 그린 그라데이션 + 🔔 `보강 교사 (알림)` 노란 종 아이콘 헤더
  - **셀 및 카드 강조**: 은은한 민트 톤 배경(`td.td-highlight-sub`) + 하얀 둥근 뱃지 카드(`sub-teacher-card`)에 **체크박스 및 [확인완료/미확인] 배지** 적용
- 📅 **기간 빠른 선택 (오늘 / 이번 주 / 이번 달 / 전체 보기)**:
  - 접속 시 자동으로 **오늘** 날짜의 보강 목록 표시
- 🏷️ **사용자 관리형 보강 사유 퀵 태그 (조퇴/외출 분리)**:
  - `#조퇴`와 `#외출` 분리, `[+ 태그 추가]` 지원
- 🔍 **드롭다운 기반 교실 & 사유 열 필터**:
  - **`🔄 필터 초기화` 버튼**: 모든 열 필터 원클릭 초기화
- 🔓 **전 교사 작성 및 수정 가능**: 누구나 자유롭게 등록, 수정, 삭제, 전달 확인 가능
- 📊 **구글 스프레드시트 DB 자동 연동**: 데이터베이스(`보강알리미_DB`) 자동 연동 및 이력 영구 저장 (`ID | 날짜 | 교시 | 교실 | 원교사 | 보강교사 | 사유 | 등록시각 | 확인여부`)
