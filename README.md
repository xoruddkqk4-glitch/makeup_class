# 🏫 보강 알리미 (온라인 교무실 보강 현황 웹 앱)

구글 사이트(Google Sites) 기반 온라인 교무실에 임베드하여 사용하는 **학교 보강 관리 및 현황 공유 웹 애플리케이션**입니다.  
구글 사이트 임베드 환경에 최적화하여 **상단 세로 공간 및 모달창 높이를 대폭 축소한 콤팩트 레이아웃**으로 디자인되었습니다.

---

## 📌 주요 기능 (Key Features)

- 🚪 **'학급' ➔ '교실' 체계 전면 개편 (구글 스프레드시트 DB 포함)**:
  - **DB 열 이름**: 기존 `학급` 열 이름 ➔ **`교실` 열 이름으로 자동 수정/생성**
  - **교실 범위**: `지하(B01~B14)`, `1층(101~115)`, `2층(201~216)`, `3층(301~316)`, `4층(401~416)`
  - **등록 모달**: 층 선택(`지하(B층)`, `1층`, `2층`, `3층`, `4층`) ➔ 해당 층의 교실 목록 자동 갱신선택
  - **테이블 열 필터**: 드롭다운 유지 (전체 교실, 지하(B층) 전체, 1층 전체, 2층 전체, 3층 전체, 4층 전체 및 개별 교실 선택)
- ↔️ **구글 사이트 전용 2열 가로 확장 모달창 (태그 확장 대응 최적화)**:
  - 좌측 열: `1. 날짜` ➔ `2. 교시` ➔ `3. 교실` ➔ **`4. 보강 교사`**
  - 우측 열: `5. 보강 유발 사유(커스텀 태그)` ➔ `6. 결강 교사(원교사)`
- 📐 **구글 사이트 임베드 전용 초슬림 콤팩트 레이아웃**:
  - 부가 설명 텍스트 및 중복 마진 제거 ➔ **'보강 알리미' 메인 제목만 슬림하게 배치**
  - 조작 패널을 테이블 헤더 툴바 내부로 완전 통합하여 세로 여백 최소화
- 🔔 **보강 교사 열 특별 시각화 강조 (핵심 기능)**:
  - **헤더 강조**: 진한 에메랄드 딥 그린 그라데이션 + 🔔 `보강 교사 (알림)` 노란 종 아이콘 헤더
  - **셀 및 카드 강조**: 은은한 민트 톤 배경(`td.td-highlight-sub`) + 하얀 둥근 뱃지 카드(`sub-teacher-card`)에 **큰 볼드 텍스트 및 [보강] 배지** 적용
  - **필터 강조**: 🔔 `보강교사 검색...` 필터 입력란도 에메랄드 포인트 처리
- 📅 **기간 빠른 선택 (오늘 / 이번 주 / 이번 달 / 전체 보기)**:
  - 접속 시 자동으로 **오늘** 날짜의 보강 목록 표시
  - **`이번 주`**, **`이번 달`**, **`전체 보기`** 퀵 버튼으로 간편한 기간 조회
- 🏷️ **사용자 관리형 보강 사유 퀵 태그 (조퇴/외출 분리)**:
  - `#조퇴`와 `#외출` 분리
  - `[+ 태그 추가]` 버튼으로 커스텀 사유 태그 생성 및 삭제 가능 (`localStorage` 자동 저장)
- 🔍 **드롭다운 기반 교실 & 사유 열 필터**:
  - **교실 필터**: 전체 교실, 층별 전체(지하, 1~4층), 개별 교실 선택 드롭다운
  - **사유 필터**: 사유 태그 목록 기반 드롭다운 선택
  - **`🔄 필터 초기화` 버튼**: 모든 열 필터 원클릭 초기화
- ✏️ **아이콘 전용 깔끔한 수정 및 삭제 버튼**:
  - 텍스트 줄바꿈 없는 깔끔한 아이콘 형태(`title` 툴팁 지원)의 수정 및 삭제 버튼 제공
- 🔓 **전 교사 작성 및 수정 가능**: 권한 제약 없이 누구나 자유롭게 등록, 수정, 삭제 가능
- 📊 **구글 스프레드시트 DB 자동 연동**: 데이터베이스(`보강알리미_DB`) 자동 연동 및 이력 영구 저장 (`ID | 날짜 | 교시 | 교실 | 원교사 | 보강교사 | 사유 | 등록시각`)
