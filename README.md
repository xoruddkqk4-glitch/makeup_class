# 🏫 보강 알리미 (온라인 교무실 보강 현황 웹 앱)

구글 사이트(Google Sites) 기반 온라인 교무실에 임베드하여 사용하는 **학교 보강 관리 및 현황 공유 웹 애플리케이션**입니다.  
구글 사이트 임베드 환경에 최적화하여 **상단 세로 공간 및 모달창 높이를 대폭 축소한 콤팩트 레이아웃**, **보강 교사 전달 확인 체크박스**, **0초 즉시 반응 낙관적 UI 성능 최적화**가 적용되어 있습니다.

---

## 📌 주요 기능 (Key Features)

- 🚨 **'긴급' (당일 보강 변경) 선택 토글 & 검색 필터 기능 (디자인 고도화)**:
  - **보강 등록 모달**: 토글 버튼 활성화/비활성화 상태의 **ON/OFF 시각적 대비 극대화** (ON 시 붉은 톤 배너 + `🚨 ON` 뱃지 전환)
  - **헤더 셀 버튼 그룹 검색 필터**: 첫 번째 `날짜(요일)` 하단 셀에 **'전체', '일반', '🚨긴급' 세그먼트 버튼 그룹** 배치
  - **테이블 행 전체 시각적 강조**: 긴급 보강 항목에 '긴급' 텍스트 뱃지 대신 **행 전체 연분홍 배경 + 좌측 강렬한 레드 테두리 포인트** 적용
  - **자동 긴급 조건 해제 (컴퓨터 시각 기준)**: 보강 날짜가 지나 다음 날(컴퓨터 local 시각 기준)이 되면 자동으로 긴급 상태 해제 및 `🚨긴급` 검색 필터 자동 제외
  - **구글 스프레드시트 11번째 열 (`긴급여부`) DB 연동**: 백엔드 11번째 열에 긴급 여부 자동 기록 및 이력 관리
- 💬 **교내 메신저용 '검색 결과 개조식 텍스트 복사' 기능 (`📋 텍스트 복사`)**:
  - 교내 메신저(쿨메신저, 카카오톡, 팀즈 등)로 해당 교사들에게 보강 내역을 원클릭 전달할 수 있는 **개조식 텍스트 복사** 버튼 제공
  - `• 교시   |   교실   |   교과   |   [보강] 보강교사  ⬅️  [원교사] 원교사   |   [사유] 사유 (✅본인확인)` (1항목 1줄 정갈한 개조식 포맷 및 18px 대형 서식 HTML 지원)
- 🏷️ **검색 날짜 정보 위치 재배치 (상단 대시보드 타이틀 이동)**:
  - 검색 날짜 뱃지(`[ 2026-09-04 (금) ]`)를 상단 `보강 알리미` 제목 옆으로 배치하여 시각적 가독성 및 툴바 가로 공간 확보
- 📄 **기간 검색 결과 A4 Portrait PDF 다운로드**:
  - `html2pdf.js` 기반 원클릭 **A4 Portrait(세로)** 표준 규격 PDF 보고서 자동 생성
  - 제목, 검색 기간, 출력 일시, 총 건수 및 깔끔한 인쇄용 데이터 표(보강 교과 포함) 작성
- ↔️ **테이블 열 순서 개편 및 '보강 교과' 열 추가**:
  - `날짜(요일)` ➔ `교시` ➔ `교실` ➔ **`보강 교과`** ➔ `보강 교사` ➔ **`결강 교사(원교사)`** ➔ **`보강 사유`** ➔ `작업` 순서로 개편
  - 열 제목 '보강 교사(알림)'을 깔끔한 **'보강 교사'**로 텍스트 수정
- 📚 **모달 창 항목 순서 테이블과 일치 & 필수/선택 표시 고도화**:
  - **항목 순서 통일**: Step 6을 `결강 교사(원교사)`, Step 7을 `보강 유발 사유`로 변경하여 테이블 열 순서와 완벽 일치
  - **필수 항목 명확화**: 1~5번 항목(`1. 날짜`, `2. 교시`, `3. 교실`, `4. 보강 교과`, `5. 보강 교사`) 전체에 시각적 **`(필수)`** 빨간색 뱃지 표시
- ✅ **보강 교사 전달 확인 체크박스 (뱃지: `✅ 본인확인` / `🔔 미확인`)**:
  - **셀 내 체크박스 배치**: 보강 교사 셀 카드 내부에 **체크박스** 및 **`🔔 미확인` / `✅ 본인확인` 뱃지** 배치
  - **원클릭 확인 토글**: 보강 교사가 해당 명단을 확인하고 체크박스를 클릭하면 카드 전체가 에메랄드 톤(`✅ 본인확인`)으로 즉시 변경
  - **DB 상태 자동 저장**: 체크 여부가 구글 스프레드시트 10번째 열(`확인여부`)에 비동기로 자동 저장
- ⚡ **데이터 등록/수정/삭제/체크 & 기간 검색 반응 속도 획기적 향상 (0초 즉시 필터링 성능 최적화)**:
  - **날짜 기간 검색 0초 즉시 반영**: 첫 로딩 시 전체 데이터를 브라우저 메모리 캐시(`allFetchedRecords`)에 보관하여, `오늘`, `이번 주`, `이번 달`, `전체 보기`, `날짜 선택` 변경 시 네트워크 대기 없이 **0.0초(0ms) 만에 즉시 결과 표시**
  - **낙관적 UI (Optimistic UI)** 적용: 등록/수정/삭제/체크박스 토글 즉시 0초 만에 화면 변경 및 백그라운드 DB 동기화
- 🚪 **'학급' ➔ '교실' 체계 전면 개편 (드롭다운 순서: 4층 ➔ 3층 ➔ 2층 ➔ 1층 ➔ 지하)**:
  - **교실 범위**: `4층(401~416)`, `3층(301~316)`, `2층(201~216)`, `1층(101~115)`, `지하(B01~B14)`
- 🔔 **보강 교사 열 특별 시각화 강조 (핵심 기능)**:
  - **헤더 및 셀 강조**: 에메랄드 그린 배경 + 뱃지 카드(`sub-teacher-card`)에 **체크박스 및 [본인확인/미확인] 배지** 적용
- 📅 **기간 빠른 선택 (지난달 / 지난주 / 오늘 / 이번주 / 다음주 / 이번달 / 전체 보기)**:
  - 접속 시 자동으로 **오늘** 날짜의 보강 목록 표시
- 🔍 **드롭다운 기반 교실, 교과 & 사유 열 필터**:
  - **`🔄 필터 초기화` 버튼**: 모든 열 필터 원클릭 초기화
- 📊 **구글 스프레드시트 DB 자동 연동**: 데이터베이스(`보강알리미_DB`) 자동 연동 및 이력 영구 저장 (`ID | 날짜 | 교시 | 교실 | 보강교과 | 원교사 | 보강교사 | 사유 | 등록시각 | 확인여부`)
