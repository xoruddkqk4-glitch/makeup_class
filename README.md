# 🏫 홍익-보강 알리미 (온라인 교무실 보강 현황 웹 앱)

구글 사이트(Google Sites) 기반 온라인 교무실에 임베드하여 사용하는 **학교 보강 관리 및 현황 공유 웹 애플리케이션**입니다.  
홍대부여고 온라인 교무실의 '교사 지도표' 디자인 스타일(청록색 테마, 깔끔한 테이블 그리드)을 반영하여 보강 내역을 시각적으로 명확하게 제공합니다.

---

## 📌 주요 기능 (Key Features)

- 📅 **날짜별 보강 현황 조회**: 달력 데이트피커, '오늘' 버튼 및 '전체 보기'로 원하는 날짜의 보강 내역을 손쉽게 필터링
- 🔍 **실시간 검색**: 원교사명, 보강교사명, 학급(예: 1학년 2반) 및 사유 키워드로 보강 내역 즉시 검색
- ➕ **모달 기반 보강 등록** (입력 순서 준수):
  1. **날짜 지정**: 달력 피커 UI (기본값: 오늘 날짜)
  2. **교시 선택**: 1교시 ~ 7교시 원클릭 칩 버튼
  3. **학급 선택**: 1~3학년 x 1~9반 드롭다운 선택
  4. **원교사(결강 교사) 입력**: 텍스트 직접 입력
  5. **보강 교사 입력**: 텍스트 직접 입력
  6. **보강 유발 사유 입력**: 텍스트 직접 입력 및 퀵 태그 (`#출장`, `#연가`, `#병가`, `#공가`, `#특별휴가`, `#조퇴/외출`)
- 🔓 **전 교사 작성 및 삭제 지원**: 별도 권한 구분 없이 누구나 자유롭게 보강 등록 및 삭제 가능
- 📊 **구글 스프레드시트 DB 자동 연동**: 데이터베이스(`홍익_보강알리미_DB`) 자동 연동 및 이력 영구 저장

## 📋 사용자 요청 및 반영/검증 결과 (User Request & Verification)

### [User Request]
- 온라인 교무실 첫 화면에 첨부 이미지('교사 지도표') 스타일 적용
- 업무 담당자와 일반 교사의 구분 없이 누구나 등록/수정 가능하도록 설정
- 교사 이름은 드롭다운이 아닌 텍스트 직접 입력으로 변경
- 입력 순서: 날짜 ➔ 교시 ➔ 학급 ➔ 교사 이름 ➔ 보강 사유

### [Action & Verification Results]
- **`Code.gs` 백엔드 구현**: `doGet()`, `getSubstitutionRecords()`, `addSubstitutionRecord()`, `deleteSubstitutionRecord()` 및 스프레드시트 자동 생성 기능 추가
- **`index.html` UI 구현**: Deep Teal(`#006b67`) 컬러 테마, Noto Sans KR 폰트, 교사 지도표 형태의 테이블 및 모달 팝업 구현
- **브라우저 검증 완료**: 메인 대시보드 렌더링, 날짜 필터링, 모달 팝업 동작 및 폼 인터랙션 정상 확인 완료

2. **웹 앱 배포**:
   - 우측 상단 **[배포] ➔ [새 배포] ➔ [웹 앱]** 선택
   - **실행 대상**: `나 (Me)`
   - **액세스할 수 있는 사용자**: `모든 사용자 (Anyone)`
   - 배포 후 생성된 **웹 앱 URL** 복사
3. **구글 사이트 임베드**:
   - 구글 사이트 편집기에서 **[삽입] ➔ [URL로 삽입]** 선택 후 복사한 URL을 붙여넣고 게시합니다.
